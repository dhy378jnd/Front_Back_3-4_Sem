## 📖 О репозитории

Данный репозиторий содержит **лабораторные работы, практические задания и семестровые проекты**, выполненные в рамках дисциплины **«Фронтенд и бэкенд разработка»** в **IV семестре**.

В отличие от предыдущего этапа изучения веб-разработки, данный курс был направлен на создание более сложных приложений с использованием современных инструментов разработки.

В ходе работы были изучены технологии взаимодействия между клиентской и серверной частью, контейнеризация приложений, работа с сетевыми соединениями в реальном времени и использование расширенных возможностей GitHub для управления проектами.

---

## ✨ Основные направления работы

- ⚙️ Разработка клиентской и серверной части веб-приложений
- 🐳 Контейнеризация приложений с помощью Docker
- 🔌 Реализация взаимодействия в реальном времени через WebSocket
- 🌐 Работа с веб-протоколами и клиент-серверной архитектурой
- 📦 Управление зависимостями и окружением проекта
- 🔄 Организация разработки через GitHub
- 📋 Работа с ветками, изменениями и историей проекта
- 🚀 Подготовка и запуск веб-приложений в различных окружениях

## 🔀 Работа с GitHub

В рамках данного курса использовались расширенные возможности GitHub:

- создание и управление ветками;
- отслеживание изменений;
- сравнение версий проекта;
- работа с Pull Request;
- проверка состояния веток;
- организация структуры разработки через несколько веток.

## 🐳 Docker

В рамках курса была изучена работа с Docker:

- создание контейнеров;
- настройка окружения приложения;
- запуск сервисов через контейнеры;
- управление зависимостями проекта;
- использование Docker для упрощения развертывания.

Контейнеризация позволила запускать проекты в одинаковом окружении независимо от локальной конфигурации компьютера.

Одной из ключевых тем курса стала работа с WebSocket.

- обмен сообщениями в реальном времени;
- обработка событий соединения;
- применение WebSocket для интерактивных веб-приложений.

## 🚀 Запуск проекта

Клонирование репозитория:

```bash
git clone https://github.com/dhy378jnd/Front_Back_IV_semester.git
```

Переход в директорию проекта:

```bash
cd Front_Back_IV_semester
```

Выбор необходимой ветки:

```bash
git checkout sem_exc
```

Для проектов с Docker:

```bash
docker-compose up
```

Дальнейшие инструкции по запуску зависят от конкретной лабораторной работы.
